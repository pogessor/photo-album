\# Photo Album with AI-powered Descriptions



Personal project to learn modern Java backend development and full-stack architecture.



\## Tech Stack



\- \*\*Backend:\*\* Java 21, Spring Boot 4.x, Spring Data JPA, Hibernate

\- \*\*Database:\*\* PostgreSQL 16 (Docker)

\- \*\*File Storage:\*\* Local filesystem (planned: S3 migration)

\- \*\*AI:\*\* Google Gemini API (planned)

\- \*\*Frontend:\*\* React (planned)

\- \*\*Build:\*\* Maven

\- \*\*Containerization:\*\* Docker, Docker Compose



\## Features



\- \[x] Photo entity with metadata (year, description, filename)

\- \[x] REST API: list, get by ID, search by year or description

\- \[x] File upload infrastructure (storage service abstraction)

\- \[ ] File upload endpoint

\- \[ ] Gemini API integration for auto-description

\- \[ ] React frontend with gallery and search

\- \[ ] Full Docker Compose setup
